# 🛒 TiendaOga - Sistema de Gestión y Ventas

Un sistema integral desarrollado en C# y .NET para la administración eficiente de productos, ventas y control de usuarios de una tienda. 
---

## 🚀 Características Principales

Este proyecto es una aplicación que permite gestionar las operaciones diarias de la tienda:

* **Gestión de Usuarios y Roles:**
  * Sistema de autenticación seguro (Login).
  * Implementación de roles con distintos permisos (Administrador, Gerente y Vendedor).

* **Gestión de Inventario (Catálogo):**
  * Interfaz para la administración del catálogo de productos.
  * Operaciones CRUD (Crear, Leer, Actualizar, Borrar) para mantener el stock actualizado.

* **Sistema de Ventas y Facturación:**
  * Módulo para registrar las transacciones y compras de los clientes.
  * Registro detallado de cada operación en la base de datos.

* **Arquitectura y Persistencia de Datos:**
  * Base de datos robusta y relacional.
  * Consultas optimizadas y procedimientos almacenados estructurados para el manejo eficiente de la información.
